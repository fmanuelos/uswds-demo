# USWDS Demo - Component Library

A comprehensive UI component library built with **React**, **TypeScript**, and **Storybook**, following the [U.S. Web Design System (USWDS)](https://designsystem.digital.gov/) guidelines. This project demonstrates modern, accessible, and government-compliant web components.

🎯 **Now available as a shadcn-compatible registry!** Install individual components directly into your projects.

## 🚀 Quick Start

Get started with development in minutes. Run the development server and explore components in this interactive environment.

```bash
npm run dev
# Opens http://localhost:6006
```

## 📦 Component Registry

Install individual USWDS-compliant components directly into your projects using our shadcn-compatible registry.

```bash
npx shadcn@latest add hhttps://fmanuelos.github.io/uswds-demo/r/button.json
```

## ♿ Accessibility First

All components are built with WCAG 2.1 AA compliance, Section 508 standards, and include comprehensive accessibility testing.

- ✅ Keyboard navigation support
- ✅ Screen reader compatibility
- ✅ High contrast color schemes

# Development Workflow

Learn how to effectively work with our USWDS component library and contribute to the project.

## 🛠️ Local Development

Set up your development environment and start building.

```bash
npm install

# Start developing with hot reload
```

## 🧪 Testing

Run comprehensive tests including unit tests and accessibility checks.

```bash
npm test
npm run test:coverage
# Ensure quality and accessibility
```

## 🏗️ Build & Deploy

Build the component registry and Storybook for production deployment.

```bash

# Builds both registry and Storybook
```
